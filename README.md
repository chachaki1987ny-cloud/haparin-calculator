# ヘパリン投与量計算ツール
## ▶ [ヘパリン計算ツールを使う](https://chachaki1987ny-cloud.github.io/haparin-calculator/)
透析業務におけるヘパリン投与量の計算を補助するために作成したWebツールです。

## 概要

透析時に使用するヘパリンについて、設定した条件から投与量を簡単に計算できるようにしました。

日常業務で発生する計算を簡略化し、確認作業をしやすくすることを目的として作成しています。

## 主な機能

- ヘパリン濃度の計算
- 初回投与量の入力
- 持続投与量の入力
- 透析時間をもとにした投与量の計算
- 入力内容のクリア

## 使用技術

- HTML
- CSS
- JavaScript

## 制作背景

臨床工学技士として透析業務に携わる中で、日常的な計算業務をより簡単にできないかと考え、業務改善の一環として作成しました。

医療現場の小さな業務課題を、Web技術やAIを活用して改善する取り組みの一つです。
